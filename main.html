이 웹앱을 안드로이드 APK로 빌드하는 방법

Capacitor를 이용해 스토어 출시 및 파일 탐색기 ZIP 연결하기

현재 보고 계신 웹앱은 모바일 터치 제스처, 메모리 해제, IndexedDB가 모두 구현되어 있어 Capacitor로 감싸기만 하면 즉시 네이티브 안드로이드 앱(APK)으로 동작합니다.

1단계: Capacitor 초기화 및 안드로이드 플랫폼 추가

npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init ComiZip com.example.comizip --web-dir .
npx cap add android

2단계: 안드로이드 '내 파일'에서 .zip / .cbz 바로 열기 (Intent Filter)

android/app/src/main/AndroidManifest.xml의 <activity> 태그 내부에 아래 설정을 추가하면, 스마트폰 파일 관리자에서 만화 ZIP을 터치했을 때 이 앱이 연결 프로그램으로 뜹니다.

<intent-filter>
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <category android:name="android.intent.category.BROWSABLE" />
    <data android:scheme="content" />
    <data android:scheme="file" />
    <data android:mimeType="application/zip" />
    <data android:mimeType="application/x-cbz" />
</intent-filter>

3단계: Android Studio에서 APK 추출

npx cap copy
npx cap open android
